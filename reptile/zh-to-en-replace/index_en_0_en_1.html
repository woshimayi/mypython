RA Configuration

RA (Router Advertisement) can provide prefix addresses and DNS addresses to access devices on the LAN side, allowing access devices to access the network faster. Enable: Whether to enable RA configuration. Minimum waiting time: The value range should be between 3 and 1350. Maximum waiting time: The value range should be between 4 and 1800. The minimum waiting time is less than the maximum waiting time. Under normal circumstances, the access device on the LAN side will receive the prefix address and DNS address sent by the router advertisement between the maximum waiting time and the minimum waiting time. In addition to the active request of the LAN side device and the active renewal of the RAServer. Select the M field: The access device can obtain the IPv6 prefix through DHCPv6. Select the O field: The access device can obtain DNS address and other information through DHCPv6.

DHCP Configuration (IPV6)

1.Configure the IPv6 address of the gateway. 2.IPv6 dynamic address management, IP address: configure the IPv6 address range of the gateway. Start DHCP service: turn on/off the DHCPv6 service function. DNS refresh time: configure the DNS sent to the client.
