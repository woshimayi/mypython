RA Configuration
RA (Router Advertisement) can provide prefix addresses and DNS addresses to access devices on the LAN side, allowing access devices to access the network faster. Enable: Whether to enable RA configuration. Minimum waiting time: The value range should be between 3 and 1350. Maximum waiting time: The value range should be between 4 and 1800. The minimum waiting time is less than the maximum waiting time. Under normal circumstances, the access device on the LAN side will receive the prefix address and DNS address sent by the router advertisement between the maximum waiting time and the minimum waiting time. In addition to the active request of the LAN side device and the active renewal of the RAServer. Select the M field: The access device can obtain the IPv6 prefix through DHCPv6. Select the O field: The access device can obtain DNS address and other information through DHCPv6.

Enable switch, use this operation to start or stop the DDNS function. DDNS setting, use this operation to set DDNS related parameters. After the setting is completed, the new DDNS status is displayed on the interface.
Advanced NAT Configuration
ALG Configuration
ALG setting: Use this operation to turn on or off each ALG switch. After the setting is completed, the new ALG switch status is displayed on the interface.
DMZ Configuration
DMZ configuration, DMZ enable switch, use this operation to start or shut down the DMZ function. After the setting is completed, the new DMZ configuration information is displayed on the interface.
Virtual host configuration
Virtual host configuration, enable virtual server configuration, and configure the relevant information of the WAN host and virtual host. After the configuration is completed, the WAN host can access the virtual host by accessing the WAN connection (IP address of the WAN connection: WAN port).
Broadband Phone Setup
Basic Settings
SIP protocol general configuration, mainly including server configuration and function switches, phone number, password, authentication user name, etc.
Basic call controls
Voice main timer configuration.
Advanced Settings
Mainly includes 1. Secondary dialing mode configuration; 2. Registration, session; 3. Caller ID; 4. DSP transceiver gain value: used to configure the gain of two directions of voice; 5. Echo suppression: used to eliminate echo; 6. Mute suppression.
Supplementary service configuration
The configuration related to voice supplementary services mainly includes 1. hotline service configuration items and hotline destination number configuration; 2. reverse polarity switch.
Digital graph
Contains digitmap enable switch, digitmap settings
Fax Setup
Some voice function settings: 1. T38 enable switch, used to configure whether fax uses T38 transmission mode. 2. T38 a=fax enable switch, used to control whether T38 fax media in SDP carries a=fax field.
IGMP Settings
IGMP Settings
IGMP SNOOPING, bridging mode carries multicast services, both routing connection and bridge connection need to be enabled.
IGMP PROXY, carrying multicast services in routing connection mode.
MLD Settings
MLD snooping, IPv6 bridging mode to carry multicast services, both routing connection and bridge connection need to be enabled.
MLD proxy, carrying multicast services in IPv6 routing connection mode.
Home Storage
FTP server settings (after correct configuration, it can be used as a server); FTP client settings (after correct configuration, it can automatically download files from the specified server address to the storage space of the home gateway to achieve resource sharing).
UPnP Configuration
UPnP Configuration
Enable or disable the UPnP function.
