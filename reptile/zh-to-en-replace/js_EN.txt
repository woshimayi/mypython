Network Connection
Broadband connection parameter settings. After configuration, interface displays basic settings: port binding settings; protocol modes include IPv4, IPv6, IPv4/IPv6; IPv4 mode includes route and bridge, where route mode includes PPPoE (select if ISP uses PPPoE, will dynamically obtain IP address), DHCP (automatically gets IP from ISP), and Static (ISP configures static IP. Requires input: IP address, subnet mask, primary/secondary DNS. IP must be correct format: x.x.x.x); bridge mode includes Bridge (configures device as bridge between LAN and ISP); IPv6/IPv4+IPv6 modes include PPP (select if ISP uses PPPoE) and IP (automatically gets IP from ISP); basic NAT enable/disable; VLAN ID and 802.1p priority settings.

RA Configuration
RA (Router Advertisement) provides prefix and DNS addresses to LAN devices for faster access. Enable: RA enable. Min Wait Time: 3-1350. Max Wait Time: 4-1800. Min < Max. Normally LAN devices receive RA between min-max intervals. M flag: devices get IPv6 prefix via DHCPv6. O flag: devices get DNS info via DHCPv6.
